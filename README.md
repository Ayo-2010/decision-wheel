# Decision Wheel

A canvas spinner wheel that picks one option for you from a list you type in.

## Features

- Canvas wheel where every option gets its own candy colour
- Up to 12 options, one per line in the textarea
- Spin button or the Space key, with easing that slows to a natural stop
- Winning option shown in a result card with a pop animation
- History of the last 8 results, persisted between visits
- Clear history button and a Shuffle options button
- Options saved to localStorage automatically
- Friendly error message when fewer than 2 options are given

## Running it

Open `index.html` in a browser. There is no build step and no dependencies to install.
